# AEROFLOT VATSIM — общие рейсы с доступом только администратора

## Что получится
- Все посетители сайта могут смотреть опубликованные рейсы и скачивать прикреплённые документы.
- Только ваш аккаунт Supabase, добавленный в `site_admins`, сможет войти, создавать рейсы и удалять их.
- Данные и документы общие для всех устройств — они больше не хранятся только в браузере.
- Пароль администратора не хранится в файлах сайта.

## 1. Создайте проект Supabase
1. Откройте https://supabase.com/ и создайте бесплатный проект.
2. В Dashboard откройте **SQL Editor → New query**.
3. Скопируйте весь файл `supabase_setup.sql`, вставьте и нажмите **Run**.

## 2. Создайте аккаунт администратора
1. Откройте **Authentication → Users → Add user**.
2. Создайте пользователя со своим email и надёжным паролем. Если доступна настройка подтверждения email, можно подтвердить пользователя через Dashboard.
3. Скопируйте UUID пользователя.
4. В SQL Editor выполните запрос, заменив UUID:
   ```sql
   insert into public.site_admins (user_id)
   values ('PASTE-ADMIN-USER-UUID-HERE');
   ```
5. Не добавляйте аккаунт друга в `site_admins`. Ему не нужен аккаунт — он открывает сайт по ссылке и только смотрит.

## 3. Подключите ключи к сайту
1. В Supabase откройте **Project Settings → API** (в некоторых версиях интерфейса — **Data API / API Keys**).
2. Скопируйте Project URL и публичный `anon`/`publishable` key. **Не используйте `service_role` или secret key в браузере.**
3. Откройте `config.js` и замените:
   - `https://YOUR_PROJECT.supabase.co` на свой Project URL;
   - `YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY` на публичный ключ.
4. Сохраните файл.

## 4. Опубликуйте сайт
Загрузите в GitHub-репозиторий содержимое папки сайта, включая `index.html`, `config.js`, `supabase_setup.sql`, `README_RU.md` и папку `assets`. `index.html` должен находиться в корне репозитория. Если GitHub Pages уже включён, после загрузки изменения появятся по той же ссылке.

## 5. Проверьте права доступа
- Откройте сайт в обычном окне: рейсы видны, кнопки добавления нет.
- Нажмите «Вход администратора», войдите своим аккаунтом: появляется кнопка добавления рейса.
- Создайте тестовый рейс с небольшим файлом.
- Откройте сайт в другом браузере/инкогнито: рейс должен быть виден и документ должен скачиваться.
- Попробуйте войти неадминистраторским аккаунтом: у него не должно быть прав на запись.

## Важно про документы
Bucket `flight-docs` сделан публичным для скачивания по ссылкам. Это означает, что любой, кто получил URL документа, может скачать его. Не загружайте секретные, персональные или чувствительные файлы. Для документов, которые должны быть доступны только членам экипажа, потребуется private bucket и выдача временных signed URLs после авторизации.

## Устранение проблем
- Если пишет `Invalid API key`: проверьте Project URL и публичный ключ в `config.js`.
- Если рейсы не загружаются: убедитесь, что SQL успешно выполнен и таблица `flights` существует.
- Если вход успешен, но не появляется кнопка добавления: проверьте, что UUID вашего пользователя добавлен в `site_admins`.
- Если загрузка файла запрещена: проверьте storage policies и bucket `flight-docs`.
